# CS128 — Object-Oriented Programming in C++

A personal archive of CS128 coursework at the University of Illinois Urbana-Champaign, Spring 2024.

These machine problems explore object-oriented design, pointers, memory management, and data structures in C++.

## Contents

- **MP0 — Pre-flight:** Development environment setup.
- **MP1 — Hawaiian Words:** String processing and pronunciation rules.
- **MP2 — Volunteer Group Builder:** Class design and volunteer grouping.
- **MP3 — Mountain Paths:** Elevation data processing and path visualization.
- **MP4 — Seam Carving:** Content-aware image resizing.
- **MP5 — Naive DB:** Table operations and dynamic memory management.
- **MP6 — Cord:** Tree-based string representation.
- **MP7 — Illini Book:** Graph-based relationship queries.
